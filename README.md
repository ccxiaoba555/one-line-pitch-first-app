One original sentence to convince a friend who has never coded to let an AI agent build their first app idea on make.fun: they have told me that app idea a dozen times, so they just describe it once in plain words, and the agent builds a first version they can actually tap through tonight — no code from them, nothing lost if they don't like it.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (231 characters, one line, no trailing newline — the file holds exactly the line).
